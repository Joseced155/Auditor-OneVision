# Kickoff del proyecto

## Nombre del proyecto

Auditor de Siniestros

## Problema

Las aseguradoras necesitan revisar las facturas enviadas por talleres
para verificar que los cobros correspondan con el tarifario acordado.

## Solución

Desarrollar un agente de inteligencia artificial capaz de comparar
automáticamente una factura contra un tarifario oficial.

## Objetivo del MVP

Detectar sobreprecios, cobros duplicados y calcular el monto cobrado de más.
